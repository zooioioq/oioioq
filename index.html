Structure, Efficiency, Synergy

UI 표준화와 구조 설계로 프로젝트의 협업 효율을 높이는 5년 차 웹퍼블리셔, 이채영입니다. 대규모 시스템 단독 구축부터 다수의 B2B·B2C 웹 서비스 퍼블리싱을 수행하며, 단순히 화면을 구현하는 것을 넘어 프로젝트 구성원들이 가장 일하기 편한 환경을 만드는 데 집중해왔습니다. 피그마 디자인 시스템과 소스코드 변수를 완벽히 동기화하고 공통 컴포넌트 가이드를 직접 구축하여 디자인-개발 간의 소통 비용을 최소화하는 시스템적 협업을 지향합니다. 기획·디자인·개발 간의 소통 시차를 메우기 위해 Git 커밋 기록을 모니터링하며 최종 산출물의 정합성을 수호하고, 디자인 시스템의 일관성을 유지하는 꼼꼼한 교량 역할을 자처합니다. 나아가 500여 개 규모의 방대한 화면 탐색 시간을 80% 이상 단축하는 '탐색 도구'를 직접 구현하여 전파하는 등, 업무의 병목을 찾아 도구화하고 효율화하는 것에 큰 보람을 느낍니다. ‘내가 구현할 수 있는 시스템의 완성도가 높을수록 조직의 협업 효율이 늘어난다’라는 모토 아래, 단순 마크업 작업을 넘어 프로젝트 전체의 리스크를 줄이는 가장 확실한 협업 파트너가 되고자 합니다.
