프로젝트 사양
ONLY PC WEB
기술 스택
HTML, CSS, Javascript, jQuery
기여도
디자인 100% + 퍼블리싱 100%
작업 년도
2023년

웹브라우저 기반의 병원 통합 관리 시스템 구축 프로젝트입니다. 필리핀의 소규모 의원 및 병원을 타깃으로 하여, 접수 - 진료 - 예약 - 정산 등의 병원 업무들을 통합적으로 관리할 수 있는 시스템을 목표로 진행되었습니다.

화면 설계 - 디자인 - 퍼블리싱에 이르는 과정에서 기여도 높게 참여하였으며, 디자인 시에는 Figma Tool을 사용하였습니다. 퍼블리싱 시에는 기본적으로 HTML, CSS, jQuery ( javascript )를 사용하여 퍼블리싱 하였고, 추가적으로 Fullcalendar.js 및 datepicker 라이브러리를 커스터마이징하여 사용하였습니다.

의료인들이 장시간 봐야 하는 화면인 만큼, 전체적으로 채도를 낮게 설정하여 눈의 피로감을 줄이도록 디자인하였습니다. 또한 작업 중 페이지 이동이 잦아지면 사용성이 떨어지며 눈의 피로도 또한 높일 수 있으므로 진료 프로세스별로 필요한 정보를 한 페이지에 모두 담아 페이지 이동을 최소화하도록 설계하였습니다.

퍼블리싱 작업 후 vue.js 개발 환경으로 구현될 프로젝트였기에, component 단위로 나누기 용이한 마크업을 하는데 집중했습니다. 또한 비슷한 레이아웃이 반복되는 구조이기 때문에 유지보수성을 높이는데 중점을 두어 css 작업을 진행했습니다.
