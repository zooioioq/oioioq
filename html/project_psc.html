Overview

포스코의 대고객 채널 통합 및 e-Sales 고도화를 위한 차세대 마케팅 메타버스 구축 프로젝트입니다.
개별 운영되던 철강 제품 및 솔루션 소개 채널을 하나로 통합하고, CRM 솔루션 기반의 영업 포털 표준을 새롭게 정의하여 사용자 중심의 고효율 비즈니스 환경을 구축하는 것을 목표로 진행되었습니다.

💻 Publishing

1. 공통 컴포넌트 설계 및 대형 프로젝트 적응력

컴포넌트 중심의 공통 UI 마크업 및 스크립트 자산화

시스템 전반에 사용되는 Sticky BreadCrumb, Tooltip, Toggle, Toast 등 핵심 공통 컴포넌트의 마크업 구조 설계 및 기능 스크립트 개발

복잡한 외부 라이브러리 UI 스타일 최적화

대용량 데이터를 다루는 ibSheet, fullCalendar, Swiper 등의 외부 라이브러리를 프로젝트의 공통 디자인 콘셉트에 맞춰 정밀 커스터마이징 및 스타일 가이드 수립

템플릿 엔진 및 빌드 환경 신속 적응

투입 직후 기존 Git History와 공통 영역 설계 구조를 정밀 분석하여, Nunjucks 템플릿 엔진 및 SCSS 레이아웃 환경에 빠르게 적응 후 본 작업 완수
2. 제약 조건 극복 및 크로스 브라우징 문제 해결

제약 조건 하에서의 구조적 CSS 스타일링

선 개발 완료된 AI 챗봇 시스템의 신규 디자인 반영 시, '기존 마크업 구조를 절대 변경할 수 없다'는 까다로운 제약 조건 안에서 복잡한 CSS 선택자(Selector)를 활용해 마크업 수정 없이 기획 디자인안을 100% 구현

웹메일/아웃룩 환경의 이메일 폼 크로스 브라우징 대응

B2B 발주 및 알림용 사내/대외 발송 이메일 폼 제작 시, 다양한 웹메일 서비스와 아웃룩(Outlook)의 렌더링 엔진 특성을 고려한 인라인 스타일 기반 HTML 마크업으로 화면 일관성 확보
3. 프로젝트 생산성 향상 및 협업 최적화

'iframe 기반 화면 미리보기 INDEX' 자체 기획 및 개발 (공수 절감)

약 500개 규모의 방대한 퍼블리싱 화면 리스트 안에서 원하는 페이지를 신속하게 추적·검수할 수 있도록 iframe 기반 미리보기 기능을 직접 구현. 이를 통해 유사 레이아웃 탐색·검수 공수 절감

대규모 UI 가이드 준수 및 퍼블리싱 검수

대형 프로젝트 특유의 엄격한 UI 가이드라인을 준수하며 B2C 반응형 채널과 B2B 적응형(PC/Mobile) 화면을 안정적으로 구축하여 디자인 완성도 극대화
