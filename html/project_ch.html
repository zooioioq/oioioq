반응형 웹 기반의 기업 홈페이지입니다. 게시할 컨텐츠가 많지 않은 신규 기업이었기에 비주얼 이미지를 적극 활용하여 기업의 아이덴티티를 인식시키는 것을 목표로 진행하였습니다.

디자인 - 퍼블리싱에 이르는 과정에서 기여도 100%로 참여하였으며 디자인 시에는 Figma Tool을, 퍼블리싱 시에는 HTML, CSS, jQuery ( javascript ) 를 사용하였습니다.

해당 기업이 추구하는 이미지가 전문성이 느껴지는 비즈니스 기업이었기 때문에 최대한 깔끔하고 모던한 느낌으로 디자인하였습니다. 또한 대부분의 컨텐츠가 회사의 아이덴티티에 대한 설명이었기 때문에 비주얼 이미지를 적극 활용하여 내용 이해도를 높였습니다. 추가로 이미지에 마우스 hover시 애니메이션 효과를 적용하여 단조로운 느낌을 없애고 집중도를 높일 수 있도록 설계하였습니다.
