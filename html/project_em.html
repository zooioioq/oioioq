프로젝트 사양
Responsive WEB
기술 스택
HTML, CSS, Javascript, jQuery
기여도
디자인 100% + 퍼블리싱 100%
작업 기간
1 months

반응형 웹 기반의 임직원용 소규모 복지몰 구축 프로젝트입니다. 임직원들이 개인의 선호도에 따라 원하는 복리후생을 선택적으로 사용할 수 있는 사이트 구축을 목표로 진행되었습니다.

디자인 - 퍼블리싱에 이르는 과정에서 기여도 높게 참여하였으며, 디자인 시에는 Figma Tool을 사용하였습니다. 퍼블리싱 시에는 HTML, CSS, jQuery ( javascript ) 를 사용하였습니다.

회사에서 제공하는 복지 프로그램인 만큼, 회사의 아이덴티티 컬러를 적극적으로 활용하고, 밝고 즐거운 분위기를 컨셉으로 디자인하였습니다. 사이트 특성상 복지 서비스에 대해 설명이 필요한 부분들은 아이콘을 활용하여 전달력 및 이해도를 높이고, 전반적으로 사용성에 중심을 두어 복잡하지 않도록 심플하게 디자인하였습니다.

사내에서 장기적으로 운영할 사이트임을 고려하여, 추후 후임자가 급하게 수정을 하게 되어도 쉽게 구조를 파악할 수 있도록 간결하고 깔끔한 마크업을 하는데 중점을 두어 작업하였습니다.
